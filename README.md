# AE2 上传侧栏 · AE2 Upload Sidebar

在 AE2 样板编码终端旁选择供应器，直接上传已编码样板，并用私人备注、图标与收藏整理你的机器和子网。

## 功能

- 点击供应器上传一张已编码样板，显示目标名称和可用样板槽位。
- 搜索供应器原名或私人备注，支持中文、英文、拼音全拼与首字母。例如“注魔祭坛”可搜 `zhumojitan` 或 `zmjt`。
- 点击行右侧星标收藏置顶；同名供应器分别保存，搜索条件仍对收藏项生效。
- 右键供应器行编辑私人备注。从背包拿起物品后点击图标，或从 JEI 拖入物品替换图标，不消耗物品；Shift＋右键图标恢复默认。
- 中键点击供应器行，关闭终端后查看目标的黄色穿墙轮廓，持续 60 秒。
- 在世界中直接打开样板供应器，也可管理它的备注、图标、收藏和映射。
- 有映射时按映射后的机器名推荐；没有映射时按配方类别名查找。可逐条开启自动上传：新编码完成后，仅在唯一可用目标匹配时上传一张，多目标仍手动选择。
- ExtendedAE Plus 为可选集成：安装时共用它的映射和管理页；未安装时使用独立映射管理。
- 面板可移动、折叠、调整宽度与行数，提供 AE2 与原版风格。原版风格跟随界面资源包。

## 环境与安装

当前文件：0.12.1-beta（Beta），Minecraft Java 1.21.1，NeoForge 21.1.241 或更新，AE2 19.2.17 至低于 19.3 的版本。

退出游戏，将 JAR 放入实例的 `mods` 文件夹；升级时移出旧版侧栏 JAR，同一实例只保留一版。保留 AE2 及其自身依赖。此文件不适用于 Forge、Fabric、1.20.1 或 1.12.2。

完整联机功能需要客户端和服务器安装本模组，不是纯客户端模组。本次测试覆盖单人内置服务器；独立多人服务器尚未专项实测，建议先在测试实例验证。

可选功能：JEI 图标拖放需要 JEI；从 JEI 捕获处理配方类别需要 JEI 和 AE2 JEI Integration；无线样板编码终端支持已测试的 AE2WTLib WET。ExtendedAE Plus 不是必装依赖。

## 使用说明

1. 在样板编码终端完成编码，在侧栏选择目标供应器上传。
2. 若都是“ME接口”等同名目标，先中键定位，再为实际目标填写备注或替换图标。
3. 处理配方请通过 JEI 的转入按钮填入终端后编码。旧处理样板本身不保存类别，必要时重新转入或手动搜索。
4. 在“映射”页面逐条开启自动上传。仅打开开关、放入旧样板或手动选择搜索词不会触发自动上传。

备注、图标和收藏仅自己可见，按世界/服务器与供应器位置保存，不改方块原名或网络连接。同位置重建可能继承旧标记，移动设备后需要重新标记。图标只影响显示。

客户端命令：`/ae2sidebar off` 关闭，`/ae2sidebar on` 恢复，`/ae2sidebar unhighlight` 取消定位，无需 OP。

## 测试与限制

0.12.0-test 已通过 107 项单元测试，以及 AE2 19.2.18 下独立模式和 EAEP 1.6.2＋CozyUI+ v1.10 组合的游戏测试。未承诺所有整合包、第三方终端或未来依赖版本均兼容。当前界面文字主要为中文。

拼音使用随包字典，运行时无需联网。多音字按备选读音匹配，可能出现额外结果。第三方数据来自 mozillazg/pinyin-data，MIT 许可随 JAR 保留。
